# AmaranthQTLdb website

Static site (React + Vite + Tailwind) for the AmaranthQTLdb compilation, adapted from the
CottonQTLome and WheatQTLdb V3.0 sites.

```
npm install
npm run dev        # http://localhost:5173
npm run build      # -> dist/
```

`public/data/`, `public/figures/` and `src/lib/genomes.json` are generated by
`python3 ../scripts/export_site_data.py` from `../data/curated/` - do not edit by hand.

The genome map draws each locus on the current assembly of its species (A. hypochondriacus v3,
A. tuberculatus hap1, A. palmeri hap1) using the converted coordinates of `../scripts/liftover.py`;
`src/lib/map.ts` switches genome with `setGenome()`.
